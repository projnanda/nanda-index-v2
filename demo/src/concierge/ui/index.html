Concierge

An AI agent arranges lunch between two people whose companies each run their own agents. It finds each company, works out who to ask, checks a restaurant and books a table — keeping a signed record of every step, including the ones that were refused.

This books a real table at the demo restaurant and writes to both companies’ agents. It takes about a minute.
